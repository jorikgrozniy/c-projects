# decimal

Реализация десятичного числа с фиксированной точкой на C11 - аналог `System.Decimal`.

## Формат

```c
typedef struct s21_decimal {
  uint32_t bits[4];
} s21_decimal;
```

- `bits[0..2]` - 96-битная мантисса.
- `bits[3]` - знак (бит 31) и степень 0..28 (биты 16..23).
- Диапазон: ±79 228 162 514 264 337 593 543 950 335.

## API

- Арифметика: `s21_add`, `s21_sub`, `s21_mul`, `s21_div`.
- Сравнения: `==`, `!=`, `<`, `<=`, `>`, `>=`.
- Конвертации: `int` ↔ `decimal`, `float` ↔ `decimal`.
- Округления: `s21_floor`, `s21_round`, `s21_truncate`, `s21_negate`.

## Реализация

- Промежуточные вычисления - в `s21_big_decimal` (`uint32_t data[7]`, 192 бита).
- Деление в столбик с остатком и нормализацией степеней.
- Банковское округление при переполнении мантиссы.
- Коды ошибок: `0` - OK, `1` - переполнение, `2` - потеря значимости, `3` - деление на 0.
