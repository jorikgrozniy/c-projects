# bash_utils

Клоны Unix-утилит `cat` и `grep` на C11. Каждая утилита - отдельный исполняемый файл с собственным Makefile.

## s21_cat

`cat/s21_cat.c`

- Флаги: `-b`, `-e`, `-E`, `-n`, `-s`, `-t`, `-T`, `-v`.
- GNU-опции: `--number-nonblank`, `--number`, `--squeeze-blank`.
- Обработка нескольких файлов, побайтовое чтение, вывод непечатаемых символов.

## s21_grep

`grep/s21_grep.c`

- POSIX `regex.h`.
- Флаги: `-e`, `-i`, `-v`, `-c`, `-l`, `-n`, `-h`, `-s`, `-f`, `-o`, включая комбинированные (`-iv`, `-in`).
- Поиск по нескольким файлам, вывод имён файлов и номеров строк.

## Сборка и тесты

```sh
cd cat  && make && make test
cd grep && make && make test
```

`make test` собирает утилиту и сравнивает её вывод с системными GNU `cat`/`grep` через `diff`. Check не требуется.
