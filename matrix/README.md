# matrix

Библиотека матричной алгебры на C11. Матрица - динамический `double**` с размерами.

```c
typedef struct matrix_struct {
  double **matrix;
  int rows;
  int columns;
} matrix_t;
```

## API

- Создание и удаление: `s21_create_matrix`, `s21_remove_matrix`.
- Операции: сложение, вычитание, умножение на число, умножение матриц, транспонирование.
- Определитель, матрица алгебраических дополнений, обратная матрица.
- Сравнение с точностью `EPS = 1e-6`.
- Коды возврата: `0` - OK, `1` - некорректная матрица, `2` - ошибка вычисления.

## Реализация

- Проверка указателей и размеров до вычислений.
- Определитель - рекурсивное разложение Лапласа по первой строке.
- Алгебраические дополнения - через миноры.
- Обратная матрица - транспонированная матрица алгебраических дополнений, делённая на определитель.
- Освобождение всех временных матриц.
